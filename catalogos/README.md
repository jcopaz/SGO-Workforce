# Catálogos extraídos do RASF

Fonte analisada: `RASF ELET.xlsx` com **3,986 registros** e **77 colunas**.

Arquivos gerados preservam os valores observados e incluem frequência para priorizar saneamento. Esses arquivos não são catálogo definitivo de produção. Precisam de governança, normalização e validação da Eletroeletrônica.

Principais números:
- sintomas distintos: 53;
- tipos de solicitação: 10;
- sistemas: 5;
- impactos/tipos: 4;
- componentes causadores: 148.

Não incluímos o arquivo RASF original no ZIP, para evitar duplicação de dados operacionais. Os catálogos derivados são a camada de trabalho.
