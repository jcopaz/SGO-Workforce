# Guia para Copilot Studio

Use os documentos deste pacote como fonte de conhecimento. Priorize `24_PROMPT_MASTER.md`, regras de negócio, arquitetura, modelo de dados e glossário.

## Tópicos sugeridos
- explicar produto e escopo;
- orientar técnico sobre estados da jornada;
- esclarecer motivo de bloqueio;
- informar fila offline/sincronização;
- explicar campos de falha;
- orientar PCM sobre indicadores.

## Limite
O agente conversacional não deve alterar registros críticos sem fluxo autenticado e ação explícita. Respostas não substituem validação da aplicação.
